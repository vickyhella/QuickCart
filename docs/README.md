## 标记说明

- **已实现**：代码或配置已具备；不代表已通过生产验收。
- **待实现**：缺少代码或流程，尚不能按预期使用。
- **待端到端验证**：主要代码已具备，需要在指定环境完整操作并记录结果。
- **待讨论**：产品或运营规则尚未决定。
- **待核验**：文档里仍是未完成项，但当前环境状态还没有证据。

验收记录写入对应文档；长期未完成事项继续保留在 PRD 首页，避免在多份文档维护重复的待办清单。
