# Ginny Nana 电商上线检查清单

这份清单按当前 QuickCart 的 Next.js、Payload、Neon、Cloudflare R2、PayPal 架构整理。它记录人工验收证据，不代表代码待办；PRD 首页是项目未完成事项的唯一清单。

**文档状态：** 验收清单模板，尚无已填写的本地验收记录。配置说明见 [Commerce 指南](./commerce-setup.md)，所有文档入口见 [docs/README.md](./README.md)。

标记规则：`已实现，待E2E` 表示主要代码存在但尚未完整验收；`待处理/待核验` 表示还缺实现、配置、运营决定或验收证据。只有实际走完流程并记入文末记录，才勾选为已验证。

## P0：上线前必须验证

- [ ] **已实现，待E2E**：访客可以从商品列表进入详情，选中当前支持的 Length + Shape + Size 组合；Mystery Box 支持 Size-only 并将正确 Variant 加入购物车。商品级 Color 筛选已实现，需验证筛选结果及详情页不要求选择颜色；Pack quantity 等通用变体组合见 PRD 首页。
- [ ] **已实现，待E2E**：禁用、缺货或不存在的 Variant 无法加入购物车；服务端应重新核对价格、库存和商品发布状态，不信任浏览器提交值。
- [ ] **已实现，待E2E**：手机和桌面端购物车、地址填写、运费展示和 PayPal 结账；下单前明确展示总价及适用费用。
- [x] **Sandbox 单笔端到端已验收（2026-10-23）**：PayPal 付款确认后站内订单显示 Paid。
- [ ] **Production Live 待验收**：Live 配置和部署已完成；待真实付款后确认 `PAYMENT.CAPTURE.COMPLETED` Webhook 验签和订单状态，并补测取消、失败、重复通知、金额 / 币种、优惠和库存。订单完成、优惠次数和库存更新目前不是原子事务，相关风险见 PayPal 专项文档。
- [ ] **待核验**：订单支付状态、查询、履约、取消、退款和部分退款流程。
- [ ] **待运营配置与E2E**：支持国家、地址格式、配送范围、运费及时效与商店政策；不支持的目的地应被明确阻止。
- [ ] **待运营确认**：联系方式、隐私政策、服务条款、配送 / 退换政策可从结账和页脚找到，且内容符合实际运营。
- [ ] **已实现，待安全验收**：Payload 管理端和 Studio 登录保护；顾客 API 不返回供应商 SKU、采购链接或其他后台字段。
- [ ] **待运维验证**：Neon 和 R2 备份及恢复方法；用备份演练恢复商品、订单和媒体引用。
- [ ] **待运维验证**：生产错误日志、关键支付、下单及媒体上传失败的发现和定位流程。

## P1：日常运营必须顺手

- [ ] **已实现，待E2E**：新商品默认 Draft；保存草稿不会公开，发布需要明确操作，编辑已发布商品可安全保存并继续发布。
- [ ] **部分实现，待E2E**：Length + Shape 明确配对与尺码生成；Mystery Box 可使用 Size-only；同步后保留匹配 Variant 的数据。商品级 Color 分类筛选已实现，不作为 Variant 维度。Pack quantity 等通用变体组合仍待开发，见 PRD 首页。
- [ ] **已实现，待E2E**：首页 By Length / By Shape 筛选仅呈现有启用 Variant 的维度值，结果与商品详情可购买规格一致。
- [ ] **已实现，待媒体验收**：商品主图、图库和 Variant 图片支持媒体库选择；验证失败上传清理及删除被引用媒体的警告。
- [ ] **已实现，待E2E**：批量编辑的搜索、分页、选择和状态修改；保存失败应指出失败项且不丢失未保存编辑。
- [ ] **已实现，待E2E**：复制商品生成新 ID / SKU 并以 Draft 开始；核验资料和库存继承规则。
- [ ] **已实现，待隐私验收**：供应商 SKU 与采购 URL 仅后台可见，不进入 Storefront、商品 JSON-LD、Google / Pinterest Feed 或顾客 API。
- [ ] **已实现，待运营验收**：Google Merchant 与 Pinterest Feed 的价格、库存、图片、链接、币种、国家和商品状态符合实际配置；商品变更后能及时更新。
- [ ] **待核验 / 补缺口**：低库存、缺图、无效 SKU、缺少价格和发布失败商品的管理筛选，以及修复后重试能力。
- [ ] **待运营决定**：订单通知、顾客确认邮件、客服入口和发货流程的负责人及操作步骤。
